## Features

- **Always on top** — A borderless, frameless strip that floats above every application. No taskbar entry to hunt for, no window to raise. Glance, and carry on with what you were doing.
- **Your contracts, not a watchlist** — NIFTY 50 plus two option contracts you pick. Type the symbol once and it is there every morning. No dashboard to configure, no columns to arrange.
- **Expiry in your face** — A live days-to-expiry counter sits next to the index, counting down to *Today*. Contracts that expire are dropped on their own, so the strip never fills up with dead positions.
- **Reconnects without you** — Laptop slept, Wi-Fi dropped, server restarted — it notices, backs off, and reconnects. Prices dim while it is offline so you are never reading a stale number as a live one.
- **One key, no passwords** — The widget holds a single revocable key, never your password. Paste it once. Lost the laptop? Delete that key on the website and it stops updating within the minute.
- **Featherweight** — One executable, no installer, no admin rights, no background updater. It talks to one server on one port and asks nothing else of your machine.

## Running in about a minute

1. **Create an account** — Email and a password. Confirm the link sent to you: https://nifty-widget.kolkataonweb.com/signup
2. **Generate a key** — One click on your dashboard. Copy it.
3. **Paste it into the widget** — Right-click → Settings. It connects immediately.
